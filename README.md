# crowdcoding-demo

A tiny sandbox repo used to demonstrate [crowdcoding](https://github.com/augbastos/crowdcoding)
end to end: a signed contribution arrives as a native pull request, the maintainer-side
GitHub Action posts a verified seal, and merging lands the change credited to the
contributor's verifiable GitHub identity.

[![Contribute with crowdcoding](https://crowdcoding.pages.dev/badge.svg)](https://crowdcoding.pages.dev/go?repo=https://github.com/augbastos/crowdcoding-demo)

`calc.py` is intentionally tiny — the kind of thing a first low-risk contribution fixes.
